# Hivemind — 3-minute demo script

Before recording: open the demo workspace (`/w/demo`), then in the sidebar choose **Reset data**.

| Time | Scene | What to show |
|---|---|---|
| 0:00–0:20 | **Problem** | Company knowledge is scattered across docs, tickets, chat and GitHub. People can't find who knows what or why a choice was made, and every sprint plan starts from scratch. |
| 0:20–1:00 | **Ask** | Click "Who should I ask about Kafka consumer lag?". The search steps appear live, then a cited answer, and the graph zooms to the evidence. Point out that Tomas *knows* Kafka while Priya *owns* the Event Bus. Click a citation to open the source. |
| 1:00–1:20 | **Knowledge risks** | Sidebar → **Knowledge risks**. Betweenness, PageRank and connected components reveal key connectors, single-expert systems and stalled work. |
| 1:20–1:50 | **Plan** | Sidebar → **Documents** → Sprint plan → Checkout Redesign. The blocker PAY-52 is scheduled first, owners are filled in, and every line is cited. Switch to PRD for Auth Service. |
| 1:50–2:15 | **Stays current** | Sidebar → **Add knowledge** → post the prefilled message from Maya. DEC-1 becomes outdated, and the Ledger sprint plan now includes the CockroachDB rollout. |
| 2:15–2:45 | **Your company** | Home → **Create a workspace** → **Add knowledge** → import `FalkorDB/falkordb-py` from GitHub. Within seconds it knows the contributors, experts and open work. Show **Connections** (Slack, Jira, Linear, GitHub, Teams). |
| 2:45–3:00 | **Close** | One private FalkorDB graph per company: cited answers and plans, knowledge that stays current, and it runs in the cloud or fully offline. |
