Slack

New messages in channels the bot is in flow into the brain automatically, and anyone can type /brain who owns checkout? to get a cited answer in Slack.

  1. Copy the app manifest, then on api.slack.com/apps choose Create New App → From a manifest and paste it.
  2. Click Install to Workspace, then paste the Bot User OAuth Token and the Signing Secret (Basic Information) below.
  3. In Slack, invite @Company Brain to the channels it should learn from.
No Slack app? Upload a Slack export instead

Post updates to a channel

Paste an incoming-webhook URL from Slack, Discord, Microsoft Teams or Google Chat. The brain announces new and replaced decisions there, and every answer, PRD and sprint plan gets a Send to channel button.

Jira, Linear, GitHub, Zapier & more

Point any tool's webhook at your private URL. Issues become tickets, comments become messages, and decisions are detected automatically.

  • Jira: Settings → System → Webhooks → Create, events: Issue created/updated, Comment created.
  • Linear: Settings → API → Webhooks, resources: Issues and Comments.
  • GitHub: repo Settings → Webhooks, content type application/json, events: Issues, Issue comments, Pull requests.
  • Microsoft Teams, Notion, Google Docs, email and others: use Zapier, Make or n8n to POST {"text": "...", "author": "...", "channel": "..."}.
