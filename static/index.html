Slack

Messages from channels the app is added to are captured automatically, and /hivemind <question> returns cited answers in Slack.

  1. Copy the app manifest, then on api.slack.com/apps select Create New App → From a manifest.
  2. Install the app, then paste the Bot User OAuth Token and Signing Secret.
  3. Add @Hivemind to the channels it should learn from.
Import a Slack export (.zip) instead

Workspace admins can export data from Slack under Settings → Import/Export data. The archive is read in your browser; only messages are uploaded.

Channel notifications

An incoming-webhook URL from Slack, Discord, Microsoft Teams or Google Chat. New and replaced decisions are posted there, and answers and documents can be shared to it.

Jira, Linear, GitHub and other tools

Send webhooks to this private endpoint. Issues are stored as tickets and comments as messages; decisions are detected automatically.

  • Jira: Settings → System → Webhooks. Events: issue created/updated, comment created.
  • Linear: Settings → API → Webhooks. Resources: Issues, Comments.
  • GitHub: Repository settings → Webhooks, content type application/json.
  • Microsoft Teams, Notion, email: via Zapier, Make or n8n, posting {"text", "author", "channel"}.
